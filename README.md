Laboratorio de Algoritmos y Programación

Este repositorio contiene la implementación y análisis de tres ejercicios desarrollados durante el laboratorio, enfocados en la resolución de problemas mediante algoritmos en Python.
Cada punto aborda una situación diferente y se incluye su respectiva explicación, resultados y código fuente.

Contenido

Punto 1 – Matriz de Satisfacción (Optimización de distribución)
Se parte de una matriz de satisfacción entre distintas posiciones o personas, con valores del 0 al 10.
El objetivo es encontrar la mejor disposición que maximice la satisfacción total.

Mejor disposición encontrada: [0, 4, 1, 2, 5, 3]

Satisfacción total: 80

Este ejercicio aplica técnicas de búsqueda y evaluación de combinaciones para determinar el mejor orden posible.
Se evalúan todas las posibles configuraciones y se selecciona aquella con el puntaje máximo de satisfacción.

Punto 2 – Problema del Cambio de Monedas (Greedy Algorithm)
Se busca cambiar una cantidad de dinero utilizando el menor número de monedas posibles.

Monto a cambiar: $63

Monedas disponibles: [50, 20, 10, 5, 1]

Monedas seleccionadas: [50, 10, 1, 1, 1]

Total de monedas usadas: 5

Este punto implementa el algoritmo greedy, donde se elige la moneda de mayor valor disponible en cada paso hasta completar el monto deseado.

Punto 3 – Juego Piedra, Papel o Tijera
Se simula un conjunto de 10 rondas del clásico juego. En cada una, el jugador compite contra un oponente que selecciona jugadas predeterminadas.

Resultado de las rondas: El jugador pierde en todas las partidas.

Resumen final:

Ganadas: 0

Perdidas: 10

Empates: 0

Este ejercicio refuerza el manejo de estructuras de control y comparación de decisiones mediante condicionales.

Resultados Generales

Se aplicaron distintos enfoques algorítmicos (búsqueda, voraz, simulación).

Se logró obtener soluciones óptimas o funcionales en cada problema.

Se comprendió el impacto de la lógica algorítmica en la eficiencia y resultados obtenidos.
